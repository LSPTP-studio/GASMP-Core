# GASMP Furniture Pack

Original Blockbench furniture for GASMP, designed for RP Engine.

## Contents
- Oak Chair: sit point and a backrest rock animation.
- Velvet Sofa: sit point and a cushion bounce animation.
- Dining Table: small interaction animation.
- Prismatic Crystal Lamp: pulsing crystal and light level 14.
- GASMP Arcade Cabinet: animated joystick and buttons.
- GASMP Champion Trophy: spin animation.

## Install
1. Install a current RP Engine release compatible with the Paper 26.2 build.
2. Copy `gasmp_furniture/` into `plugins/RPEngine/content/`.
3. Run `/rp reload` and inspect the console for model or YAML warnings.
4. Test placement, removal, seats, light, chunk reloads and Java/Bedrock appearance on staging.

Animated furniture plays its model animation on right-click. Shift-right-click uses seats on the chair and sofa.
