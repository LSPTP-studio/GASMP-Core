# GASMP Furniture Pack

This pack contains original GASMP furniture content for RP Engine.

## Included model

- `gasmp_modern_sofa.bbmodel`: editable Blockbench 5 project, 33 cubes, six named groups, embedded texture and `sit_press` cushion animation.
- `gasmp_modern_sofa.png`: matching 128x128 texture atlas.

## Install

1. Back up the server and resource pack.
2. Copy the complete `gasmp_furniture` folder into `plugins/RPEngine/content/`.
3. Use the content reload and resource-pack generation workflow documented by the exact RP Engine release installed on the server.
4. Test the item on Java and Geyser Bedrock clients before distributing it.

The item definition is a placeable decorative model. The `sit_press` animation is authored in the model; actual interaction-trigger behavior depends on the installed RP Engine version and needs in-game validation.
