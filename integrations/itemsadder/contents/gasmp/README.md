# GASMP ItemsAdder content

Namespace: gasmp

This folder defines 96 cosmetic reward IDs, the Normal/Medium/Premium crate keys, and the three placeable crate furniture items expected by GASMP Core 0.8.2. Furniture and hat items use ItemsAdder behaviours. Model files use built-in Minecraft block textures with self-contained GASMP starter geometry. Replace starter models with licensed original source art when available, keeping item IDs and model paths stable.
