# GASMP ItemsAdder 4.0.18 content

This folder is the GASMP ItemsAdder content pack for **ItemsAdder 4.0.18**.

## Install
1. Install the official ItemsAdder 4.0.18 plugin JAR in the server's `plugins/` folder.
2. Start the server once and let ItemsAdder create `plugins/ItemsAdder/contents/`.
3. Stop the server and copy `contents/gasmp/` and `contents/gasmp_ranks/` into that `contents/` folder.
4. Start the server, run `/iareload`, and fix any YAML/model warnings.
5. Run `/iazip` and ensure ItemsAdder sends the updated resource pack to clients.

Do not put ItemsAdder.jar inside its own data directory.

This pack includes six themed crate models and keys, custom furniture, wearable cosmetic models and rank/badge art. The VoidRP UI is a separate plugin and uses a separate stacked resource-pack request; its UI pack does not replace the ItemsAdder content pack.

Official ItemsAdder installation guide: https://wiki.itemsadder.com/plugin-usage/first-install/
