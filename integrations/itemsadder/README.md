# Deprecated: ItemsAdder integration

GASMP Core no longer uses ItemsAdder as a runtime dependency. The supported custom-content provider is RP Engine.

The rank image/font files formerly stored under this directory have been moved to:
- integrations/rp-engine/content/gasmp_ranks/
- integrations/rp-engine/content/rank_bundle/

For installation, wearable cosmetics, crate keys, animated crate blocks and displays, follow integrations/rp-engine/README.md and use the GASMP RP Engine Test Pack archive. Do not install this old ItemsAdder export on the server.
