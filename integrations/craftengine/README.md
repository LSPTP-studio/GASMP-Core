# GASMP CraftEngine content pack

Install the included `gasmp/` folder into `plugins/CraftEngine/resources/gasmp/` after CraftEngine has generated its resources directory. Run `/ce reload all` to load the 108 items, 40 furniture definitions and 125 images. Models and PNGs are under `resourcepack/assets/gasmp/`.

The original `gasmp:<id>` item IDs remain unchanged. The optional VoidRP UI plugin is a separate plugin and its own pack is sent separately; it does not replace CraftEngine's content pack.

CraftEngine documentation: https://xiao-momi.github.io/craft-engine-wiki/getting_start/project_structure/
