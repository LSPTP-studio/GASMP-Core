# GASMP Phase 2 rank-art source files

These are the three original rank-art archives supplied by the GASMP owner for Phase 2:

- `72-icons-source.zip` — 72 small badge/icon textures.
- `chiaki-haruma-rank-bundle-source.zip` — rank emblem set with ItemsAdder content/config.
- `pixed-free-prefix-pack-source.rar` — prefix images in English and other language folders.

The normalized ItemsAdder import generated from these assets is already in:
`integrations/itemsadder/contents/`

Phase 2 will use these sources to create the GASMP rank selection, TAB/chat prefix visuals, Owner and Developer panels, and rank-up cinematic. The source files are retained as provided; review the asset authors' usage terms before publishing or redistributing any resulting pack.
